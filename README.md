# SAP Security and SoD Conflict Detector
This project is a Python based tool designed for automated segregation of duties conflict auditing in SAP systems. It cross-references user authorization data against an established risk matrix to generate detailed analytical Excel reports. By relying on a standardized structure of SAP roles and Transaction Codes (T-Codes), the script enables fast, repeatable audits and easily scales across diverse SAP environments. This standardized approach eliminates manual verification, significantly reduces data processing errors, and seamlessly integrates with automated unit testing.
